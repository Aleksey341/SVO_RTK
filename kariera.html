Корпоративный университет

Корпоративный университет предлагает широкий спектр образовательных программ, специально адаптированных для ветеранов СВО. Наши программы учитывают уникальный опыт военной службы и помогают трансформировать его в востребованные профессиональные компетенции.

Обучение проходит как очно, так и дистанционно. Для ветеранов все программы предоставляются на льготных условиях или бесплатно.

Программа для тех, кто имел опыт командования. 3-месячный курс по современным управленческим практикам, проектному менеджменту и лидерству. Бесплатно для ветеранов СВО.
Технические специальности: электрика, сантехника, строительство, эксплуатация оборудования. Сертификаты государственного образца. Практические занятия на базе производственных объектов.
Профессиональная переподготовка на охранника, специалиста по пожарной безопасности, специалиста по охране труда. Специальный трек для ветеранов с ускоренным получением допуска.
Программирование, системное администрирование, работа с данными. 6-месячные интенсивные курсы с гарантированным трудоустройством по окончании для ветеранов СВО.
